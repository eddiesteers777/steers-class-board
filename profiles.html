Student Profiles

One profile per roster name, filled by every game: Vault Raid, and the team games when teams come from the Group maker. Level is topic locks cracked, not time played. Only you can see this page.

How profiles work
  • Who. One profile per roster name for each period, first name and last initial only. A typed name that matches the roster plays as that profile. A name that matches nobody gets no profile.
  • Topic locks. A topic is the question's Alabama standard (from its skill, like "AL 7.10a"), or the skill name. A lock cracks at 5 right, 6 of the last 8 right, on 2 different days. Cracked locks never lock again. Level = locks cracked.
  • Accuracy. In Vault Raid only the first try counts. A fix after a miss earns XP and coins but doesn't raise accuracy. In team games each member gets the team's result ("with team" below), which is team evidence, not proof one student knows it.
  • XP and coins. 10 XP for a right answer, 6 for a fix, 1 for every try, 6 for a team right, 50 for a cracked lock. Each right answer banks 10 coins (5 for a fix or a team right). Getting cracked in a game never touches the bank. Whole-class games (Class vs. Teacher, Rapid Fire, Bingo, Tug of War) give each student present up to 20 XP and no topic record.
  • Nothing is ever taken away. No streak loss for being absent, no lost XP, no lost locks. Students see only their own profile, never a list.
  • Writes. Only your Remote writes profiles, once a game, after it ends (teacher/{you}/profiles/{period}). Students never write to it.
