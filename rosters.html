Rosters

One name per line for each period. Names are saved only to your private account and are never part of the site's public code. The Name picker and Group maker use them. First name and last initial is all the board needs.

Import a class list

A CSV from Google Classroom, PowerSchool, your gradebook or a sheet (File, Download, CSV). With a Period or Class column, each student goes to their period. Names are cut to first name and last initial before anything is saved.

Paste everything at once

Paste a full list with a line such as "1st period" above each class, then choose Fill the boxes. Check the boxes, then Save rosters.
